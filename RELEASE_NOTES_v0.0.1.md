# Release Notes — PixelForge Windows v0.0.1 🎨⚡🖌️💎

We are pleased to release **PixelForge Windows v0.0.1**!

PixelForge — современный, высокоскоростной редактор пиксель-арта на базе .NET 8, Avalonia UI 11 и аппаратно-ускоренного рендеринга SkiaSharp.

---

## 🌟 What's New in v0.0.1

### 1. 🎨 Multi-Layer Canvas Engine (Многослойность)
- **Слои без ограничений**: добавление, удаление, слияние вниз (Merge Down), дублирование, регулировка непрозрачности (0..100%) и видимости.
- **Porter-Duff Source-Over Compositing**: математически корректное сведение слоев в реальном времени.

### 2. ⚡ SkiaSharp Hardware Acceleration (Рендеринг без сглаживания)
- **Чистый Nearest-Neighbor**: масштабирование от 1x до 32x с фокусом на курсор без размытия пикселей (SKFilterQuality.None).
- **Zero GC-Alloc**: кэширование SKPaint и оффскрин-буферов при кадровой отрисовке.
- **Адаптивная сетка**: отображение пиксельной сетки при зуме >= 4x.
- **Симметрия X / Y**: зеркальное отражение в реальном времени для всех рисующих инструментов.

### 3. 🖌️ Full Pixel-Art Tool Arsenal
- **Карандаш (B)**: непрерывный штрих с интерполяцией Брезенхейма.
- **Ластик (E)**: стирание в честный альфа-канал.
- **Заливка (G)**: 4-связный алгоритм BFS Flood Fill с защитой от переполнения стека.
- **Пипетка (I)**: мгновенный сэмплинг цвета со слоя или композитного холста.
- **Линия (L)**: отрисовка отрезков по алгоритму Брезенхейма с предпросмотром.
- **Прямоугольник (R/U) & Эллипс (C)**: контурные и залитые фигуры (Midpoint эллипс).
- **Выделение (S/M)**: перемещение, вырезание, копирование, вставка (Ctrl+C, Ctrl+X, Ctrl+V).

### 4. 💽 Палитры, История & Экспорт
- **Встроенные ретро-палитры**: DawnBringer 32 (Default), PICO-8 (16), GameBoy (4 DMG), NES (54) и расширенный RGBA ColorPicker.
- **История Undo/Redo**: разреженные дельты пикселей (PixelDelta) на 150 шагов (< 1 МБ памяти).
- **Live Preview 1x**: плавающий предпросмотр арта в истинном масштабе 1:1, 2x и 4x.
- **Экспорт**: PNG с прозрачностью и 24/32-bit BMP без искажения цветов.
- **Автосохранение**: фоновое сохранение аварийной копии в AppData.
