# Release Notes - PixelForge Windows v0.1.6

## 🚀 Что нового / What's New

### 📐 Произвольные размеры холста и сетки (до 4096×4096 px) / Arbitrary Canvas & Grid Dimensions
- **Снятие ограничения 256×256 px при создании холста:** Теперь можно создавать холсты любого размера — от 1×1 до 4096×4096 px (включая популярные форматы 500×1000, 1920×1080 Full HD, 2048×2048).
- **Диалог размера холста (`ResizeCanvasDialog`):** Поддержка изменения размеров до 4096 px с сохранением якоря размещения (3×3) и Nearest-Neighbor масштабирования, добавлены быстрые пресеты 512×512 и 1024×1024.
- **Новый пресет 512×512 в `NewCanvasDialog`:** Быстрое создание больших холстов в один клик.

### ⚡ Высокопроизводительный рендеринг сетки (Viewport Culling)
- **Умное отсечение линий сетки (`RenderPixelGrid`):** Отрисовываются только те линии пиксельной сетки, которые реально попадают в видимую область вьюпорта (`LocalClipBounds`). Никаких тысяч невидимых линий за пределами экрана — стабильные **60+ FPS** при рисовании и панорамировании холстов любого размера.
- **Расширенный диапазон зума (5% – 6400%):** Минимальный масштаб уменьшен с 100% до 5% (`MinZoom = 0.05f`), позволяя легко отдалить и обозревать гигантские холсты целиком. Автоматический комфортный начальный зум для больших проектов.
